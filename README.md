## Доказательства и ограничения
Официальные страницы Sinoasia проверены. Научная опора: две депонированные аннотации и одна полнотекстовая конференционная работа; для обзора отмен страхования подтверждены только метаданные, его выводы не использованы. Работа не утверждает измеренный спад продаж в Sinoasia или достигнутый эффект. Клиентские данные и тестирование внутренних сервисов не проводились. Задание не отправлено в Product Masters.

## Воспроизведение
Python 3.12; ReportLab 4.4.9, PyMuPDF 1.26.6 и fontTools 4.61.1 (точные установленные версии сверить с `docs/quality-review.md`). Из корня репозитория: `python scripts/generate_pdf.py`. Скрипт читает единственный источник текста `docs/case-study-ru.md`, создаёт PDF и PNG. Шрифты Inter включены с лицензией OFL; файлы получены из официального репозитория Google Fonts и инстанцированы в Regular/Bold. PDF использует нейтральный деловой дизайн без логотипов; соответствие брендбуку BCC не заявляется.

Срок из задания: 17 октября 2026 года, 23:59 UTC+5. Для сдачи загрузить PDF в Product Masters; GitHub — дополнительная ссылка. Границы доступа к научным текстам раскрыты в реестре источников.
